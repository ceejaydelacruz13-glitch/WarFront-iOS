Start here

A WarFront mod is a folder of small text files. You do not need to program, and you need no tools but a text editor. You write what you want changed, and the game does the rest.

A mod can do any of these, alone or together:

  • Change the game's numbers: a tank's price, how much a rig pumps, how long a building takes.
  • Add units, buildings and weapons, each based on one of the game's own.
  • Add weather, map events and bot personalities, and change what every side starts with.
  • Give the game a new look and sound without changing any rule: pictures, colours, recordings, music.
  • Add new systems with a short script.

Your first mod in five steps

  1. In the game, go to WORKSHOP, then MODS, and press MY MODS FOLDER. The folder opens, empty the first time. (MODDER'S GUIDE, beside it, opens this page and keeps a copy of it in that folder.)
  2. Make a folder in it with a name of your own: letters, digits and dashes.
  3. Make a file mod.json in your folder, copy the one from the example at the end of this page into it, and change "id" and "name". The id must be different from every other mod's.
  4. Make a file rules.json beside it. For a first try, put only this in it: { "units.tank.cost": 50 }
  5. Back in the game, press REFRESH on the MODS list, switch your mod on, and start a war. Tanks cost 50.

You cannot break the game. A number that is too big or too small is brought back within reach. A word the game does not know is passed over. And whatever your files got wrong is listed for you in the game, with the file, the entry and the reason: open your mod's card and press PROBLEMS.

How the files are written

All but the script are JSON: names in double quotes, a colon, a value, commas between entries, everything in braces. A missing comma or quote is the usual mistake, and PROBLEMS tells you which file has it.

In the files that add things, each entry has a key: a short name of your own, in lower-case letters, digits and dashes (up to 24). In a war your thing's full id is your mod's id, a dash, and the key. So the unit heavy-tank of the mod my-mod is my-mod-heavy-tank. Inside your own files you always use just the key.

Nearly every new thing says "like": the game's own thing it is based on. It starts as an exact copy, and you write only what differs. That is why a whole new unit can be three lines.

rules.json: change the game's numbers

The game keeps every number of its rules in one big table: 3749 of them that a mod may change. Each has a place, written with dots: units.tank.cost is the tank's price.

You may write them flat or nested. These two files do the same thing:

{ "units.tank.cost": 120, "rigs.oilPerSec": 1.8 }
{ "units": { "tank": { "cost": 120 } }, "rigs": { "oilPerSec": 1.8 } }
  • Only numbers and switches. A switch is true or false. Names and lists are not rules.
  • Kept within reach. A number may be no more than 100 times bigger or smaller than the game's own. A price may also be 0. One that was 0 may go up to 100000.
  • A few are locked and no mod may change them: match.tickHz, match.cellScale, match.scriptedEnd, dev.*.
  • Distances are in cells of a test map. The game scales them to the map the war is fought on, so write them as the game does.
  • With several mods on, a later mod's number wins over an earlier one's. The order is the order of the MODS list.

Abilities

AbilityWhat the unit can then do
engineerAn Engineer Team's work: mend roads and buildings, plant charges on an enemy's road, dig trenches, cap a blowout.
reconA Scout Car's work: it deploys to see far. A side may have only a few.
carryA ground vehicle takes squads on foot aboard. seats says how many.
rideA unit on foot may be carried.
smokeA ground vehicle pops a smoke screen when it is hit.

Two abilities come only with the base and cannot be handed out: a unit like command is a Mobile HQ, and a unit like demo blows itself up. A unit like para is trained at the Barracks for a price. A unit like demo with no from is made at the Free Brigades' Demolition Yard, for its kills; named elsewhere it costs the Bomb Truck's oil. Bots buy and use all of them.

A unit like mortar sets up to fire as the Mortar Team does, sniper picks men off from afar, and aatruck fights aircraft. The airport's f35, chinook are no base: they are built only in an airport's shelters, so a mod naming one is told so.

Armies

Each army fields the game's units in its own look, and some only in one army (the Mortar Team the Coalition's, the Sniper Team and the Anti-Air Truck the Free Brigades'). Yours goes to the armies its base goes to, and wears its base's look in each: the Free Brigades' trucks, the Republic's camouflage, on the map, its wreck, its tiles and its card. Where an army has its own make of the base (the Free Brigades' Mortar Truck, the Republic's Missile Launcher), yours is that army's make too, but for what you write yourself. "armies": ["coalition", "republic"] gives it to exactly those armies instead.

Voices

The answers a unit may have lines for: select, ready, move, attack, retreat, garrison, load, unload, trench, repair, dig, fill, sabotage, mines, barrage, recon, deploy, detonate, dive, surface, torpedo, cruise, cluster, nuke, airstrike, bomber, drones, aircraft. A unit with no voices of its own speaks with its base's; a unit's lines go through the same voice volume as the game's, never two at once.

A unit like carrier or cruiser is a ship. She is bought in the NAVAL tab and laid down at the harbour, so from does nothing for her. A side has one carrier and one cruiser at a time, the game's or a mod's.

Pictures and sounds of your own

The game only provides the slots. The files are yours: draw them in any paint program.

Pictures

  • PNG, with a clear (transparent) background, no bigger than 1024 pixels either way and 1.5 MB.
  • Seen from straight above, pointing up. The game turns it to the way the thing faces. Up is the front.
  • The mask is a second PNG of exactly the same size. Where it is white, the side's colour is painted at full strength; grey paints it darker; clear paints nothing. Without a mask the picture wears no colour.
  • A vehicle is one picture, and may have its turret as a second one that turns on its own.
  • Men on foot are one picture of one man. The game draws the whole squad from it. "frames" adds his walking steps.
  • A ship or an aircraft is one picture, turned whole. No turret.
  • A building is its whole yard from above. While it is built it goes up bottom first, by its "heights" picture or by how light it is.
  • The path is written from your mod's folder with forward slashes: "art/heavy.png". Use plain names: letters, digits, dashes and underscores. A path that leaves your folder is refused.

Units that may bring a picture are the ones based on: tank, ifv, aatruck, artillery, rocket, engineer, scout, infantry, at, mortar, sniper, para, carrier, cruiser, submarine, patrol, droneboat. Any unit may bring a portrait for the panels.

Sounds

  • OGG, WAV or MP3, up to 8 MB a file.
  • A sound played once (a gun) may be up to 12 seconds. A looping one may be up to 3 minutes, and music up to 10 minutes.
  • The game evens out the loudness of your recording to match its own, so you need not.
  • A mod's recordings are kept up to 160 at once, for all the mods that are on together: a unit's voice lines count among them.
  • A unit may have a gun (fireSound), an engine (engineSound, a loop), a death (deathSound) and a voice (voices). Any it leaves out is its base's.

script.js: new systems

A script adds a system the files cannot: relief oil for whoever is behind, a boss wave every five minutes, a button that calls in a strike. It is the file script.js.

It is written in the game's own small language, which reads like plain JavaScript. It is not real JavaScript and it can do only what the game hands it: it has no disk, no network and no screen. That is why a script from a stranger is safe to run.

How a script runs

The game runs your script once from its top as the war begins, and again whenever a save is loaded. At the top you say what you want to hear of. From then on the game calls the functions you gave it.

// Every two minutes, the side with the fewest rigs gets a little oil.
every(120, () => {
  let poorest = null
  for (const s of sides()) {
    if (!s.alive) continue
    if (poorest == null || s.rigs < poorest.rigs) poorest = s
  }
  if (poorest == null) return
  giveOil(poorest.id, 150)
  message(poorest.id, 'Relief oil has arrived.')
})

Things to know

  • Sides are numbers, from 0. Positions are x and y in cells of the map; mapSize() tells you how big it is.
  • Only state is saved. Since your script runs from its top again after a load, anything you set up at the top (buttons, handlers) is set up again by itself. Do one-time things in on('start', ...).
  • A script that goes wrong is stopped for the rest of that war, and the player is told which mod's it was. So is one that takes more than 150000 steps in one go, which is what an endless loop does.
  • To find a mistake, use log(...) and read it under PROBLEMS on your mod's card after the war. A mistake in how the script is written shows there before you even start a war, with its line.
  • Limits: a script may be 100000 characters, a list or object may hold 5000 things, and state may be 60000 characters when saved.
  • A button is pressed by a side, and your on('button', ...) is told which button and which side. Pressing is an order like any other, so it behaves the same for everyone in a war.

Testing, problems and publishing

Testing

  1. Save your files, then press REFRESH on the MODS list. Your mod is read again.
  2. If your mod's card shows PROBLEMS, open it. Each line names the file, the entry, and what is wrong.
  3. Switch the mod on and start a war against bots.
  4. While a war runs, RELOAD MODS in the pause menu reads your files again and lays the new numbers on the war as it runs. You do not have to start over to try a new price.

The mods that are on change wars against bots. A reskin is on everywhere. Up to 32 mods may be on at once.

Online. Mods work in online wars too: the host's mods go to every player in the room as text (the rules, the units, the buildings, the weapons and the rest), so everyone plays by the same rules. Pictures and sounds do not travel: a player who has your mod (subscribed on the Workshop) sees and hears them, and one who has not sees and hears each of your things as the game's thing it is based on.

  1. Open your mod's card in the MODS list and choose PUBLISH. Pick who can see it.
  2. To give its Workshop page a picture, put a preview.png in the mod's folder first: a PNG under 1 MB.
  3. To update it later, change your files and publish again from the same folder. Keep the same id.

Steam must be running. Players who subscribe get your mod in their MODS list the next time they open it.

script.js

// A script is a new system for the war. This one helps whoever is behind:
// every two minutes the side holding the fewest rigs is sent a little oil.
const RELIEF = 150

on('start', () => {
  state.sent = 0
})

every(120, () => {
  let poorest = null
  for (const s of sides()) {
    if (!s.alive) continue
    if (poorest == null || s.rigs < poorest.rigs) poorest = s
  }
  if (poorest == null) return
  giveOil(poorest.id, RELIEF)
  state.sent = state.sent + RELIEF
  message(poorest.id, 'Relief oil has arrived: ' + RELIEF + '.')
})

// A button of the mod's own in the HUD, for every side: pressing it marks
// the nearest rig nobody holds on that side's map for half a minute.
button('find-oil', 'Find oil', { tip: 'Marks the nearest rig nobody holds.' })

on('button', (id, side) => {
  if (id != 'find-oil') return
  const home = buildings({ side: side, type: 'hq' })[0]
  if (home == null) return
  let best = null
  for (const r of rigs()) {
    if (r.side >= 0) continue
    if (best == null || distance(r, home) < distance(best, home)) best = r
  }
  if (best == null) {
    message(side, 'Every rig is held.')
    return
  }
  mark(best.x, best.y, 'Free rig', { side: side, sec: 30, radius: 3 })
})
